# 여덟 이슈 결합 검증 계획

기준 main 22dc7de 위에 웹 종료·목록 검색(#119, #184, #30), 편집 서식·취소 초안(#183, #15), 관계선 접합·드래그(#199, #200), 터미널 메타데이터(#22)를 함께 적용한다. 호스트 수명과 드래그 해제, 시작 기록 세대와 복구, 편집 원본 revision, 메타데이터 기록 순서를 검증한다.

원격 Draft에는 이 계획만 올린다. 제품 검토본은 로컬에 보존한다. #24 전체 프로세스 수명 변경과 #98은 제외한다. 이미 회수한 자식에 보내는 종료 신호는 대역 검증 후에만 별도 최소 가드로 판단한다.

실제 셸 네 개를 제외한 Rust 전체, UI, fmt, Clippy, 개발 빌드와 그룹별 브라우저·호스트 대역·임시 파일 검사를 결합 소스로 실행한다. 네이티브 창·기존 메모·사용자 PTY는 조작하지 않는다. 두 기준 패치의 결과 tree를 대조하고 미검증 범위를 함께 보존한다.
