## 최종 브랜치와 재시험

기능 커밋 `7e27f7b`에서 Rust 213개·UI 183개, Clippy, 개발 빌드를 통과했다. [플랫폼 CI](https://github.com/egoing/agent-gibbon/actions/runs/42454102716)에서 Intel·Apple Silicon macOS 및 Windows 빌드와 설치 파일 조립이 성공했다.

- 최종 복원 코드를 포함한 서명 후보에서 편집 중 메모 1개, 서로 다른 터미널 2개와 웹 2개를 열었다. PID 21444의 업데이트 준비 창에 다섯 대상을 각각 표시했고 ‘업데이트하고 재시작’을 눌러도 메모 저장·취소 안내를 유지했다. 편집 취소 후 9개 창 모두 준비 응답을 보낸 기록이 남았으나 해당 회차의 앱은 종료되고 번들은 0.2.11로 남았다. 종료 원인은 확정하지 못했다.
- 별도 Intel iMac 시험에서는 검증 빌드에만 정상 수동 설치 함수를 호출하는 테스트 코드와 단계 기록을 추가하고 두 터미널의 실제 마지막 선택(shell/git) 및 웹 주소 2개를 사용했다. 지원 표시가 빠진 시험 manifest에서는 준비 전에 차단됐다. 복원 지원 표시가 있는 정상 후보로 다시 다운로드한 회차에서는 PID 19510이 창 상태 저장·패키지 검증·설치를 마치고 종료 코드 0으로 끝났으며 같은 경로의 0.2.12 PID 20929가 실행됐다. 서로 다른 웹 주소가 다시 열리고 두 터미널의 Welcome 응답에 복원 안내가 포함됐다. 이 빌드의 계측은 제품에 포함되지 않는다.
- 두 번째 시험에서 수정한 manifest는 최초 PID 21444 종료 원인을 설명하지 않는다. 화면 잠금 중 수행한 시험은 네이티브 실행 경로 검증이다. 두 터미널에 표시된 마지막 명령 문구의 화면 대조와, 무입력 30초 경계를 통과하는 동안 실제 메모가 보였는지는 이 기록에서 통과로 판정하지 않는다.
