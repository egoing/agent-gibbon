## 패키지 시험 오류의 분리

초기 수동 tar 패키징에서 macOS AppleDouble `._Jajan Resume Verification.app`가 포함되어 추출이 실패했다. 초기 8,002,324바이트 패키지의 설치 실패는 정상 설치 성공으로 세지 않았다. `COPYFILE_DISABLE=1`로 다시 패키징·서명하고 이전 시험 캐시를 별도 보관한 뒤 재시험했다. 최종 8,001,962바이트 패키지 SHA-256은 `d579c3531d6145a2d64ca8fa9d20f0d0e5241f845447cb7de7431ba28d6e370112`이다. 이 오류는 시험 자산 생성 방식에서 발생했으며 제품 코드 변경 대상에 포함하지 않았다.

## 범위와 한계

- 이번 실기기 자동 설치는 검증 프로필의 30초다. 정식 기본값 300초를 이번 SHA에서 다시 기다린 시험으로 보고하지 않는다. 기존 Intel iMac의 300초 자동 설치·PTY 보호·복원 기록은 [실기기 체크리스트](issue102-live-checklist.md)의 2026-11-08 후속 회차에 있으며 이번 변경의 통과 근거로 재사용하지 않는다.
- 이번 PTY 보호 회차는 수동 설치로 무입력 대기를 생략해 실제 작업 보호를 검증했다. 실행 중 PTY를 유지한 채 OS 무입력 30초를 넘긴 자동 시도는 이 회차에서 별도로 계측하지 않았다.
- 미저장 편집·ACK 무응답·Windows·Intel·정식 300초 프로필은 이번 실기기 재시험 범위에 포함하지 않았다. 관련 기존 자동 검사는 통과했지만 이를 실기기 실증으로 바꾸어 보고하지 않는다.
- 커밋·push·병합·배포는 하지 않았다. Conf 5는 이 Mac의 검증 프로필에서 관찰한 결함·수정 효과와 설치/복원에 한정한다. 변경 Risk Medium(앱 종료·재시작 경로), 미검증 플랫폼에는 이 확신도를 확장하지 않는다.
