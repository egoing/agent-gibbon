## 실기기 확인 항목

- OS의 선호 언어 순서를 바꾼 시험 계정에서 첫 실행, 지원 언어가 없는 경우, 저장된 명시 언어로의 재실행을 확인한다. 한국어·영어·일본어 각각에서 최초 프레임의 표시 언어와 새 환영 메모의 본문을 확인한다.
- 관리창, 편집 중인 메모, 캡처, 실행 중인 터미널, 이미 탐색한 외부 웹페이지를 함께 연다. 언어를 바꾼 뒤 메모의 편집·선택·IME, PTY PID와 출력, 웹페이지의 URL·스크롤·입력값, 창의 위치와 숨김 상태를 확인한다.
- 트레이 및 macOS 앱 메뉴, 권한 패널, 내보내기와 종료 확인 대화상자, 보조 창의 접근성 이름을 확인한다. 세 언어에서 긴 오류와 도움말, 좁은 창과 OS 화면 배율도 확인한다.
- 저장된 환영 메모와 사용자가 쓴 제목·본문·파일 경로에 메뉴와 동일한 단어를 넣고, 언어 전환 및 재실행 후 원문을 대조한다.

브라우저 재현 스크립트는 `scripts/language-browser-smoke.mjs`다. 저장소의 다른 Chromium 검사처럼 `PUPPETEER_MODULE`로 puppeteer-core 모듈을, `CHROME_BIN`으로 Chrome 실행 파일을 지정할 수 있다.
