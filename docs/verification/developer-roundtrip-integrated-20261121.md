## 통제되지 않은 첫 전환 — 성공 판정 제외

에이전트가 필수 동의·5회 클릭·이전 버전 버튼 입력을 보내기 전에 외부 입력 guard, 동의 완료 화면, 관리 창 교체가 관측됐다. 첫 PID 23432 소멸 뒤 직접 로그를 붙여 시작한 PID 26188에서 실제 파일/실행 버전이 0.3.12임을 확인했다. 저장된 설치 준비 기록은 21:51:34 KST의 0.3.13→0.3.12, 8개 창 ACK true다. 캐시 패키지 SHA-256은 준비한 0.3.12 자산과 일치했다. 이 관측만으로 자동 설치·앱 충돌·사용자 조작 중 하나를 원인으로 단정하지 않는다.

[관측 JSON](developer-roundtrip-integrated-20261121/uncontrolled-transition.json)을 보존했고, 사용자에게 전용 시험 앱 직접 조작 여부를 확인 중이다. Windows Application 1000/1001 조회에서 해당 trial 앱의 충돌 기록은 찾지 못했다. 로그를 붙여 다시 시작한 앱에서는 프로세스 생존과 개별 창 숨김을 구분했다. UI 도구의 전경 창 식별 오류도 관측했다. 원인을 분리하기 전 이 회차를 실제 메뉴·동일 셸·왕복 성공으로 사용하지 않는다.

사용자 설치 앱은 읽기 조회만 했다. 기존 PID 20272가 조회되지 않고 같은 설치 경로의 PID 6028·버전 0.3.12가 관측됐지만, trial 전환과 같은 원인이라는 근거는 없다. 이 에이전트는 사용자 설치본 종료·설치·재시작 명령을 실행하지 않았다.
