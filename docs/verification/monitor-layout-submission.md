## 판정과 최소 후속

| 완료 기준 | 현재 근거 | 남은 최소 확인 |
|---|---|---|
| 정상 창 유지·접근 불가 창 피난 | 사용자 실제 분리 후 A 불변, B/C 이동·H 숨김. CLI 기하/출처 기록 | 조작 영역의 다른 앱 겹침·모든 형태를 일반화하지 않음 |
| 재연결·직접 조작 우선 | 실제 B 원복·C 수동 이동 위치 유지 | C 직접 resize→수치 변화 확인→재연결 후 최신 크기 유지 |
| 큰 창·상태/유형 보존 | 기하·직렬화 단위 테스트, macOS 저장 fixture | 큰 창 축소, 접힘/확대/undo·실행 PTY/웹/이미지의 실제 환경 전환 |
| 저장·하위호환 | 단위 테스트, 부재/일치 화면 저장 fixture의 실제 시작 복원 | 사용자 실제 임시 피난 상태 재시작 시나리오 |
| 포커스 | CLI초기대상 누락 보강, 안정 후 원래 앱 복귀 관측 | 초기 일시 활성화는 남음. 제3앱 선택·명시 클릭·최소화 GUI 미실행 |
| 플랫폼·이벤트 | Rust246/UI189/Clippy/개발 빌드, 안정화 단위 검사 | Windows/Intel·혼합 DPI·회전/도킹/잠자기 실기기 |

전체 Conf3 / Risk Medium. 사용자 성공 보고는 보존하되 size_changed=false를 resize 실증으로 바꾸지 않는다. 사용자 최신 테스트 배치를 보존한다. 제출 시 read-only 프로세스 조회에서는 해당 개발앱이 실행 중이지 않았으며 에이전트가 종료하거나 자동 재시작하지 않았다. 실제 미완료 검증이 있는 이슈 #190은 열린 상태로 둔다. 사용자 승인에 따라 제품 커밋·push·병합 및 기본 main fast-forward 동기화를 진행하고 실제 결과는 PR·이슈 최종 댓글에 기록한다. 공개 배포·전체 플랫폼 CI·추가 GUI/모니터 설정 조작은 수행하지 않는다.
