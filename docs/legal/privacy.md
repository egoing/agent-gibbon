이 문서는 동의 화면 구현을 위한 초안입니다. 운영자는 egoing, 개인정보 문의 창구는 egoing+support@gmail.com이며, 현재 Sentry 저장 지역은 미국 아이오와로 확인했습니다. 아래 보유기간은 2026-11-06의 실제 계정 설정과 공식 문서를 조사한 내용입니다. 최종 보유기간 고지는 원본·집계·백업을 구분해 확정할 예정이며 현재 빌드의 외부 진단 전송은 비활성화되어 있습니다. 안내 내용이 바뀌면 기존 동의를 자동 승계하지 않습니다.

## 1. 동의하지 않을 때

오류 보고·성능 trace/span·구조화 진단 로그·release health 세션·프리징 감시 정보를 외부로 전송하지 않습니다. DSN이 포함된 빌드나 개발 환경변수가 있더라도 동의를 대신할 수 없습니다. 전송에 동의하지 않아도 메모·터미널 기능을 사용할 수 있습니다.

앱 기능에 필요한 메모, 캡처, 터미널 설정과 동의 선택은 로컬 기기에 저장됩니다. 사용자가 실행하는 외부 명령이나 도구의 네트워크 통신까지 이 진단 선택이 제어하지는 않습니다.

## 2. 별도 선택 동의를 받을 항목과 목적

목적은 앱 오류 수정, 성능 개선과 멈춤 원인 분석입니다. 운영 정보를 확정한 뒤 사용자가 별도로 동의한 경우에만 다음 항목을 전송할 수 있습니다.

- 앱 버전·빌드 식별값, 운영체제·CPU 아키텍처.
- 정제된 오류 종류, 허용된 앱 함수·파일 이름과 행 정보.
- 고정된 영어 작업명, 작업 시간·횟수·실패 횟수, 프리징·복구 유형과 시각.
- 사용자·장치 식별자를 제외한 진단 세션 상태와 trace 식별값.

메모 내용·제목, 터미널 입력·출력·명령, 클립보드, 화면·이미지, 사용자명·장치명·로컬 경로를 진단 자료에 포함하지 않습니다. 완전 익명이라고 보장하지 않으며, 수신 서비스는 연결 과정에서 IP 주소를 처리할 수 있습니다. IP 저장·필터 설정도 정식 전송 활성화 전에 확인합니다.

## 3. 처리업체·저장 지역·보유기간

예정 처리업체는 Sentry 서비스 제공자(Functional Software, Inc.)입니다. 계약상 처리 관계와 국제 이전 근거는 정식 배포 전에 확정합니다.

저장 국가/지역: 미국 아이오와(US 리전). Sentry 조직의 실제 regionUrl과 공식 저장 지역 문서를 대조했습니다.

현재 무료 Developer 요금제에서 확인한 보유기간:

- 오류 이벤트: 30일.
- 성능 trace/span·transaction 원본: 30일.
- 구조화 진단 로그 원본: 30일.
- 백업: Sentry 공식 안내상 데이터 종류에 따라 백업 생성 후 30일 또는 90일에 삭제합니다. 원본의 30일 보유와 동일한 시점의 완전 삭제를 뜻하지 않습니다.

집계 지표 traceMetric의 API 반환값에는 일반 30일·다운샘플 396일이 있습니다. 해당 프로젝트의 hasTraceMetrics는 false이며, 이 기능의 실제 사용·보유 여부를 원본 데이터의 보유기간과 혼동하지 않습니다. Release Health의 세션 통계와 이슈 누적 집계는 위 원본 보유기간만으로 완전 삭제를 단정하지 않으며 최종 고지에서 구분합니다.

조사 근거는 저장소의 Sentry 저장 지역·보유기간 조사 기록에 남겼습니다. 현재 문서는 최종 보유기간 고지 확정 전의 초안입니다.

최종 보유기간 고지가 확정되기 전에는 정보 전송을 활성화할 수 없습니다. 약관 동의나 이 안내 열람만으로 전송에 동의한 것으로 처리하지 않습니다.

## 4. 선택·철회·권리 행사

진단 전송 선택은 기본 해제입니다. 설정에서 언제든 끌 수 있으며, 새로운 전송을 차단하고 이전 동의 세대의 대기 자료를 보내지 않습니다. 철회 이전에 이미 시작된 네트워크 요청은 완료될 수 있으며 이미 수신된 자료의 삭제와는 구분됩니다. 열람·정정·삭제 등 개인정보 관련 요청은 egoing+support@gmail.com으로 보내 주세요. 요청 확인에 필요한 범위의 정보만 제공하고, 공개 문의에 개인정보나 진단 원문을 올리지 마세요.

동의 여부·동의 문서 버전·선택 시각은 계정/광고 식별자 없이 로컬에 기록합니다. 저장 실패나 문서 버전 불일치·파일 손상 시에는 전송을 허용하지 않습니다. 기존 로컬 자료나 이전에 서버가 받은 자료는 설정 변경만으로 자동 삭제되지 않습니다.
