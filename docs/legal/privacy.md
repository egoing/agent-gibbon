이 안내는 오류 수정·성능 개선·프리징 원인 분석을 위한 선택적 진단 전송에 적용합니다. 기본값은 전송하지 않음이며, 아래 내용을 확인하고 별도로 동의한 경우에만 전송합니다. 안내 내용이 바뀌면 기존 동의를 자동 승계하지 않습니다.

## 1. 동의하지 않을 때

오류·성능 trace/span·구조화 진단 로그·프리징 감시 정보를 외부로 전송하지 않습니다. DSN이 포함된 빌드나 개발 환경변수는 사용자 동의를 대신하지 않습니다. 동의하지 않아도 메모·터미널을 포함한 모든 앱 기능을 사용할 수 있습니다.

앱 기능에 필요한 메모, 캡처, 터미널 설정과 동의 선택은 로컬 기기에 저장됩니다. 사용자가 실행하는 외부 명령이나 도구의 네트워크 통신까지 이 진단 선택이 제어하지는 않습니다.

## 2. 선택 동의의 목적과 전송 항목

목적은 앱 오류 수정, 성능 개선과 멈춤 원인 분석입니다. 별도 선택에 동의하면 다음 진단 자료를 수집·이용하고 아래 Sentry 서비스로 이전·처리위탁·보관합니다.

- 앱 버전·빌드 식별값, 운영체제·CPU 아키텍처.
- 정제된 오류 종류, 허용된 앱 함수·파일 이름과 행 정보.
- 고정된 작업명, 작업 시간·횟수·실패 횟수, 프리징·복구 유형과 시각, 구조화 진단 로그.
- 요청·작업 흐름 연결용 trace 식별값. 영구 사용자·장치 식별자는 만들지 않습니다.

메모 내용·제목, 터미널 입력·출력·명령, 클립보드, 화면·이미지, 사용자명·장치명·로컬 경로를 진단 자료에 포함하지 않습니다. 오류 문구·소스 문맥·절대 경로도 제거합니다. 완전 익명이라고 보장하지 않으며, 연결 과정에서 IP 주소가 수신 서비스에 노출되고 서버 설정에 따라 처리·기록될 수 있습니다. 클라이언트가 IP 필드를 제거한다는 사실이 서버에서의 IP 처리를 없애지는 않습니다.

Release Health 세션·세션 통계는 보유기간을 확인할 때까지 수집하지 않습니다. 화면을 재생하는 Session Replay, 첨부파일·화면 녹화·메모리 덤프·함수별 CPU 프로파일도 전송하지 않습니다.

## 4. 원본·백업·통계의 보유기간

2026-11-06에 확인한 현재 Sentry Developer 계정과 사용자 승인 정책을 기준으로 합니다.

| 자료 | 보유·삭제 기준 |
| --- | --- |
| 오류 이벤트 원본 | 수집 후 최대 30일 |
| 성능 trace/span·transaction 원본 | 수집 후 최대 30일 |
| 구조화 진단 로그 원본 | 수집 후 최대 30일 |
| Sentry의 장애 복구용 백업 | 데이터 종류에 따라 백업 생성 후 30일 또는 90일에 삭제 |
| 오류 이슈 누적 통계 | 개별 이벤트가 만료된 뒤에도 해당 이슈가 유지되는 동안 누적 발생 횟수 등이 남을 수 있음. 원본과 같은 30일 완전 삭제를 약속하지 않으며 삭제 요청은 운영자 문의처로 접수 |
| Release Health 세션·세션 통계 | 보유기간 확인 전 수집하지 않음 |

백업은 Sentry로 전송된 진단 자료의 서버 복구용 사본이며 사용자 컴퓨터나 메모 전체의 백업이 아닙니다. 백업 삭제 기간은 원본의 30일 보유와 시작점이 같지 않습니다. 위 기준은 모든 관련 자료가 수집 후 30일 안에 완전히 삭제된다는 뜻이 아닙니다.

현재 프로젝트의 traceMetric 집계 기능은 계정 조사 당시 미사용 상태였습니다. 이 앱은 별도 metric envelope를 전송하지 않으며, 장기 집계 지표를 추가할 때는 실제 처리·보유 조건을 확인하고 안내와 동의를 갱신합니다.

근거: [계정 조사 기록](../verification/sentry-data-retention-20261106.md), [Sentry 원본 보유기간](https://docs.sentry.io/security-legal-pii/security/data-retention-periods/), [백업 삭제 안내](https://www.sentry.help/en/articles/13965019-how-frequently-is-data-backed-up), [원본 만료 후 오류 누적 통계](https://www.sentry.help/en/articles/13964336-why-does-the-event-count-in-my-issue-not-match-up-with-the-count-in-the-all-events-tab-of-the-issue).

## 5. 선택·철회·권리 행사

진단 전송 동의는 기본 해제이며 약관 동의와 별개입니다. 선택 체크는 제2~4절에 설명한 수집·이용과 Sentry 국외 이전에 대한 동의입니다. 설정에서 언제든 철회할 수 있습니다. 켜기는 명시적인 저장이 필요하고 끄기는 즉시 저장합니다.

철회하면 새로운 전송을 차단하고 이전 동의 세대의 대기 자료를 보내지 않습니다. 철회 이전에 이미 시작된 네트워크 요청은 완료될 수 있으며, 철회 완료 응답은 해당 요청의 종료를 기다린 뒤 반환합니다. 이미 수신된 자료의 삭제와 앞으로의 전송 중단은 별개입니다.

열람·정정·삭제 등 개인정보 관련 요청은 egoing+support@gmail.com으로 보내 주세요. 사용자·장치 식별자를 저장하지 않으므로 개별 자료를 찾는 데 한계가 있을 수 있습니다. 요청 확인에 필요한 범위의 정보만 제공하고, 공개 문의에 개인정보나 진단 원문을 올리지 마세요.
