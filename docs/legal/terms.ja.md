# Jajan 利用規約 — 草案

バージョン 2026-11-06.2

本草案は、egoing が提供するデスクトップアプリ Jajan の基本的な利用条件を定めます。プライバシーに関するお問い合わせ先は egoing+support@gmail.com です。一般のお問い合わせにはリポジトリの Issues も利用できます。公開の問い合わせにメモの原文、コマンド、アカウント情報などの個人情報を記載しないでください。

## 1. 提供する機能

Jajan は端末にメモ、画像、ターミナルウィンドウを表示し、ローカルのファイルとプロセスを扱います。基本機能にはアカウントやクラウド同期は不要です。利用者が実行するシェル、コマンド、外部ツールは端末の権限で動作し、外部ツールには別の利用規約やプライバシー条件が適用される場合があります。

## 2. 利用者の資料と端末

作成した資料の権利は利用者に帰属します。アプリは機能の提供に必要な範囲で端末内の資料を読み取り、保存します。重要な資料は別途バックアップし、実行するコマンド、保存先、アクセス権限を確認してください。サービス改善情報の送信は独立した選択事項で、拒否・撤回後もすべての機能を利用できます。

## 3. プライバシーと任意の診断情報

個別の同意を得るまで、エラー報告、性能情報、セッション、フリーズ診断を外部に送信しません。項目、処理委託先、保存地域、保有期間、撤回方法はプライバシー通知に記載します。運営情報が確定していない草案ビルドでは、同意の有無にかかわらず送信機能を提供しません。

## 4. 提供条件と責任

本アプリは無料のオープンソースとして提供し、特定目的への適合性、無停止の動作、資料の永久保存を保証しません。適用法令上、排除または制限できない権利・責任は維持されます。本条項は法令上の責任を一律に免除するものではありません。

## 5. オープンソースライセンス

ソースの使用、複製、変更、再配布にはリポジトリの MIT License が適用されます。本規約と同意画面は、同ライセンスが付与した権利を制限しません。第三者の構成要素には各ライセンスが適用されます。

## 6. 変更と利用終了

利用者はアプリの終了または削除により利用を中止できます。削除によって端末内の資料や送信済みの診断資料が自動で削除されるわけではありません。重要な利用条件や診断の目的・項目が変わる場合はアプリ内で提示し、必要な同意を再取得します。診断情報の送信への同意は「設定 → プライバシーと診断」でいつでも撤回できます。
