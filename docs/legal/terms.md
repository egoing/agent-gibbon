# Agent Gibbon 이용약관 — 초안

버전: 2026-11-06.1

이 문서는 Agent Gibbon 프로젝트 관리자가 제공하는 데스크톱 앱의 최소 이용 조건 초안입니다. 운영자의 정식 이름과 개인정보 문의 창구는 아직 미정입니다. 정식 배포 전에 확정하며, 현재 문의는 프로젝트 저장소의 Issues를 이용할 수 있습니다. 공개 문의에는 메모 원문·명령·계정 정보·기타 개인정보를 올리지 마세요.

## 1. 앱의 제공 범위

Agent Gibbon은 기기에 메모·이미지·터미널 창을 표시하고 로컬 파일과 프로세스를 다루는 도구입니다. 기본 기능에 계정이나 클라우드 동기화는 필요하지 않습니다. 사용자가 실행한 셸·명령·외부 도구는 해당 기기의 권한으로 동작하며 외부 도구의 별도 약관과 개인정보 처리 조건이 적용될 수 있습니다.

## 2. 사용자의 자료와 기기

작성한 자료의 권리는 사용자에게 있습니다. 앱은 기능 제공에 필요한 범위에서 기기 안의 자료를 읽거나 저장합니다. 중요한 자료는 별도로 백업하고, 실행할 명령·저장 경로·접근 권한을 확인해 주세요. 서비스 개선 정보 전송은 앱 이용과 별도의 선택이며 거부하거나 철회해도 앱 기능은 제한하지 않습니다.

## 3. 개인정보와 선택적 진단

사용자가 별도로 동의하기 전에는 오류 보고·성능 정보·세션·프리징 진단을 외부로 전송하지 않습니다. 수집 항목·처리업체·저장 지역·보유기간·철회 방법은 개인정보 안내에 따릅니다. 운영 정보가 확정되지 않은 초안 빌드에서는 동의 여부와 관계없이 해당 전송을 제공하지 않습니다.

## 4. 제공 조건과 책임

앱은 무료 오픈소스로 제공되며 특정 목적에 대한 적합성·무중단 동작·자료의 영구 보존을 보장하지 않습니다. 다만 적용 법령상 배제하거나 제한할 수 없는 권리와 책임은 유지됩니다. 이 문구는 법령상 책임을 일괄 면제한다는 뜻이 아닙니다.

## 5. 오픈소스 라이선스

소스코드의 이용·복제·수정·재배포에는 저장소의 MIT License가 적용됩니다. 이 약관이나 동의 화면은 MIT License로 이미 부여된 권리를 축소하지 않습니다. 제3자 구성요소에는 각 라이선스가 적용됩니다.

## 6. 변경과 이용 종료

사용자는 앱을 종료하거나 삭제해 이용을 중단할 수 있습니다. 삭제가 로컬 자료나 이미 전송한 진단 자료를 자동 삭제한다는 뜻은 아닙니다. 중요한 이용 조건이나 진단 목적·항목이 바뀌면 앱에서 새 내용을 제시하고 필요한 동의를 다시 받습니다. 서비스 개선 전송 동의는 Settings → Privacy & Diagnostics에서 언제든 철회할 수 있습니다.
