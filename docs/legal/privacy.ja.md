# Jajan プライバシー・サービス改善情報に関する通知

バージョン 2026-11-06.3

## 運営者とお問い合わせ

運営者は egoing です。プライバシーに関するお問い合わせ先は egoing+support@gmail.com です。一般のお問い合わせには GitHub Issues を利用できます。個人情報を公開しないでください。

本通知はエラー修正、性能改善、フリーズ原因の分析のための任意の診断情報の送信に適用します。初期設定はオフで、本通知を確認し個別に同意した場合に限り送信します。通知が変わった場合、従来の同意を自動で引き継ぎません。

## 1. 同意しない場合

エラー、性能のトレース・スパン、構造化診断ログ、フリーズ監視情報は外部へ送信しません。DSN を含むビルドや開発環境変数は同意の代わりになりません。メモ、ターミナルを含むすべての機能を利用できます。

機能に必要なメモ、キャプチャ、ターミナル設定、同意の選択は端末内に保存します。利用者が実行する外部コマンドやツールの通信はこの設定の対象外です。

## 2. 同意の目的と送信項目

個別に同意した場合、エラー修正、性能改善、フリーズ原因の分析を目的に、次の診断資料を収集・利用し、Sentry に移転して処理を委託し、保管します。

- アプリのバージョン、ビルド識別値、OS、CPU アーキテクチャ。
- 機密情報を除いたエラーの種類、許可されたアプリの関数名、ファイル名、行番号。
- 定義済みの処理名、処理時間、回数、失敗回数、フリーズと復旧の種類・時刻、構造化診断ログ。
- リクエストと処理を結ぶトレース識別値。永続的な利用者・端末識別子は作成しません。

メモの内容・タイトル、ターミナルの入出力・コマンド、クリップボード、画面・画像、利用者名、端末名、ローカルパスは含めません。エラー文、ソースの前後関係、絶対パスも除去します。完全な匿名性は保証できません。接続時の IP アドレスは受信先に見え、サーバー設定により処理・記録される場合があります。クライアントが IP フィールドを除去しても、サーバーでの処理はなくなりません。

Release Health のセッションと統計は保有期間を確認するまで収集しません。Session Replay、添付ファイル、画面録画、メモリダンプ、関数別 CPU プロファイルも送信しません。

## 3. 国外移転と処理委託先

- 移転先：Functional Software, Inc. (Sentry)。
- 移転先のプライバシー窓口：https://sentry.io/contact/gdpr/ 。アプリ運営者は egoing+support@gmail.com。
- 国・保存地域：米国アイオワ州（US リージョン）。
- 時期：同意後、アプリの利用中に診断項目が発生・集計されたとき。
- 方法：暗号化された HTTPS 接続。
- 項目：第2節の診断資料と接続時に処理される IP アドレス。
- 目的：エラー、性能、フリーズ診断の処理と運営者への分析機能の提供。
- 保有・利用期間：第4節の原本、バックアップ、累積統計ごとの基準に従います。
- 拒否方法：初回に同意しないか設定で送信をオフにします。アプリの機能は制限されません。

## 4. 原本、バックアップ、統計の保有期間

2026-11-06 に確認した Sentry Developer アカウントと承認済みの方針を基準とします。

| 資料 | 保有・削除の基準 |
| --- | --- |
| エラーイベントの原本 | 収集後最長30日 |
| 性能のトレース・スパン・トランザクションの原本 | 収集後最長30日 |
| 構造化診断ログの原本 | 収集後最長30日 |
| Sentry の障害復旧用バックアップ | データの種類に応じてバックアップ作成後30日または90日で削除 |
| エラー課題の累積統計 | 個々のイベントが期限を過ぎても、課題が存在する間は累積発生回数などが残る場合があります。30日以内の完全削除は保証しません。削除のご依頼は運営者まで。 |
| Release Health セッションと統計 | 保有期間を確認するまで収集しません |

バックアップは送信済み診断資料のサーバー復旧用コピーです。利用者の端末やメモ全体をバックアップするものではありません。バックアップの保有期間は作成時から起算し、原本の30日とは起点が異なります。関連資料がすべて収集から30日以内に完全に削除されることを意味しません。

アカウント調査時点で traceMetric 集計は未使用でした。アプリは個別の metric envelope を送信しません。長期集計指標を追加する際は実際の処理・保有条件を確認し、通知と同意を更新します。

参考：[アカウント調査](../verification/sentry-data-retention-20261106.md)、[Sentry の原本保有期間](https://docs.sentry.io/security-legal-pii/security/data-retention-periods/)、[バックアップ削除](https://www.sentry.help/en/articles/13965019-how-frequently-is-data-backed-up)、[原本の期限後のエラー累積統計](https://www.sentry.help/en/articles/13964336-why-does-the-event-count-in-my-issue-not-match-up-with-the-count-in-the-all-events-tab-of-the-issue)。

## 5. 選択、撤回、権利の行使

診断送信は初期状態でオフで、利用規約への同意とは別です。チェックすると、第2～4節の収集・利用および Sentry への国外移転に同意します。設定からいつでも撤回できます。オンにするには明示的な保存が必要で、オフは直ちに保存します。

撤回すると新規の送信を停止し、過去の同意期間に待機していた資料も送信しません。すでに開始した通信は完了する場合があります。撤回の完了応答はその通信の終了を待って返されます。受信済みの資料の削除と今後の送信停止は別の手続きです。

開示、訂正、削除などのご依頼は egoing+support@gmail.com までお送りください。利用者・端末識別子を保存しないため、個別資料の特定には限界があります。確認に必要な情報だけを提供し、公開の場には個人情報や診断資料の原文を投稿しないでください。

同意の有無、文書バージョン、選択時刻はアカウント識別子や広告識別子なしで端末内に記録します。保存失敗、ファイル破損、文書バージョン不一致の場合は送信を許可しません。設定変更だけでは既存のローカル資料やサーバー受信済みの資料は自動削除されません。
