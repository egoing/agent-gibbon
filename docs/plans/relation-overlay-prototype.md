# 메모 관계 연결 조사

두 메모 사이 방향 화살표와 관계 레이블을 개발 전용 프로토타입으로 검증한다.

- [x] 개발 인스턴스 전용 원자적 관계 파일과 클릭 통과 overlay 코드 작성 (컴파일 미확인)
- [x] 이동·리사이즈·접힘·숨김·복원·창 삭제 수명 구현·단일 macOS 검증
- [x] 디자인 시스템과 SVG/PNG 조사 시안 갱신·렌더 확인
- [x] Rust 225·UI 203·Clippy·Rustfmt·개발 빌드 통과
- [x] 인스턴스·PID·창 제목 확인 후 팀장 GUI 슬롯에서 단일 macOS 실앱 검증

공개 CLI·메모 영구 저장·서버·배포는 확대하지 않는다. 다중 모니터 배율·Space와 타 앱 가림은 확인 범위를 기록한다. 최종 제품 커밋과 병합은 승인 대기한다.

검증 장애: 디스크 공간 부족으로 Rust 빌드가 두 번 중단됐다. UI 203개·Rustfmt·공백 검사는 통과했다. Rust/실앱 단계는 공간 확보 후 계속한다.

공간 조율 후 장애 해소. 최신 빌드로 실앱 검증과 포커스 복원 확인 완료. 혼합 배율·다른 Space·Windows/Linux는 미검증. 최종 제품 커밋·push·병합 승인 대기.

## 사용자 후속 승인: 곡선과 부드러운 이동

- [x] 변경 이벤트 합치기·정지시 중복 eval/native 재배치 제거
- [x] 곡선 접점·Bézier·레이블·RAF 수렴 후 중단 구현
- [x] Rust226·UI205·Clippy·Rustfmt와 최신 native 회귀
- [x] 이전/이후 짧은 CPU 표본 비교 및 측정 범위·한계 기록
- [x] 시안 SVG/PNG 갱신·렌더 확인, 사용자 관계·포커스 복원

단일 표본에서 앱 Rust+관계 WebContent의 이동 CPU 약0.50%→0.97%(1코어 기준). 전체 GPU/전력과 장시간 부하는 미측정이며 CPU 감소를 확정하지 않는다. 최종 커밋·push·병합은 계속 승인 대기한다.

추가 정적 검토에 따른 연결 양끝 이벤트 필터를 적용했다. 최신 3회 표본: 정지0.23~0.25%, 이동0.55~0.59%(Rust+관계 WebContent/한 코어 기준). 이전 단일 baseline과 통제 조건이 충분하지 않아 인과적 성능 개선으로 단정하지 않는다.
