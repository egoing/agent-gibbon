# 메모 관계 연결 조사

두 메모 사이 방향 화살표와 관계 레이블을 개발 전용 프로토타입으로 검증한다.

- [ ] 개발 인스턴스 전용 원자적 관계 파일과 클릭 통과 overlay 구현
- [ ] 이동·리사이즈·접힘·숨김·복원·창 삭제 수명 추적
- [ ] 디자인 시스템과 SVG/PNG 조사 시안 갱신
- [ ] 관련 Rust/UI 검사와 개발 빌드
- [ ] 인스턴스·PID·창 제목 확인 후 팀장 GUI 슬롯에서 실앱 검증

공개 CLI·메모 영구 저장·서버·배포는 확대하지 않는다. 다중 모니터 배율·Space와 타 앱 가림은 확인 범위를 기록한다. 최종 제품 커밋과 병합은 승인 대기한다.
