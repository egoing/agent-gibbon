# 선택 서식 메뉴의 한국어 명칭 적용 계획

이슈 #183의 코드·큰제목·작은제목 버튼은 화면 문구, 도구 설명, 접근성 이름에 같은 명칭을 사용한다. 기존 inlineCode 명령과 제목 수준 1·2는 유지한다.

- 실제 버튼 너비와 줄바꿈을 확인하고, 좁은 창에서 메뉴 내부로 가로 스크롤할 수 있게 한다.
- Milkdown 편집기 시안의 SVG·PNG와 디자인 시스템을 실제 버튼 배치에 맞춘다.
- 독립 브라우저에서 선택 유지, 제목 수준과 코드 적용, 키보드 진입·이동·복귀, 좁은 폭을 검증한다. 실행한 환경과 실제 OS 입력기 검증 범위를 구분해 보고한다.
