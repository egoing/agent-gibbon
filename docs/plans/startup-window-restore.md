# 일반 시작 창 복원 계획

기준: origin/main 9904f10770d552b8f90ceb8073415d9875c09062. 작업 루트는 전용 af67 워크트리이며 설치 앱과 기본 체크아웃은 변경하지 않는다.

## 문제와 동작

일반 시작은 저장한 메모의 본문만 읽고 창을 숨긴 상태로 만든다. 텍스트·이미지·웹·터미널의 마지막 실제 창 상태를 인스턴스별 로컬 파일에 원자적으로 기록하고 시작 시 비포커스 복원한다. 숨김은 숨김으로, 삭제된 창은 미생성으로 구분한다. 접힌 창은 펼친 크기도 보존한다. 웹은 최근 HTTP(S) URL로 재탐색하며 이전 PTY나 입력은 재실행하지 않는다.

업데이트 복원(#118 관련)은 기존 일회성 snapshot을 먼저 적용한다. 일반 snapshot은 적용 중 덮어쓰지 않고 실행 준비 이후에만 기록한다. 정상 종료 직전과 주기적 checkpoint로 비정상 종료 손실 범위를 줄인다. 손상·과대·중복 레코드를 거부하고 모니터가 사라진 창은 사용 가능한 화면으로 보정한다.
