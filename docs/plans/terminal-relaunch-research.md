# 마지막 터미널·앱 재실행 조사 계획

기준: 2026-11-13, origin/main `9904f10770d552b8f90ceb8073415d9875c09062`.

## 문제와 목표

터미널을 종료한 뒤 다시 열었을 때 마지막 작업 앱과 폴더를 알려주고 사용자가 한 번 클릭하여 다시 실행할 가능성과 한계를 조사한다. 앱 새 실행, 대화 재개, 종료된 프로세스 복원을 구분하며 제품 구현은 하지 않는다.

## 범위

- #57, #118, #150과 현재 Welcome·추천·PTY·메타데이터를 비교한다.
- 별도 워크트리의 #150 미커밋 코드는 읽기만 하고 의존 지점을 기록한다.
- 공식 CLI 문서와 로컬 help/버전으로 Codex·Claude Code의 새 실행과 재개 옵션을 확인한다. 실제 재개와 설정 변경은 금지한다.
- 자유 명령 기록보다 앱 ID·폴더·정형 실행을 우선 검토하고 보안·보관·삭제·복수 터미널·실행 실패를 비교한다.
- 2~3개 대안, 권장 순서, 사용자 선택, 구현 시 완료 기준을 별도 조사 문서에 남긴다.

## 완료 기준과 검증

조사 문서가 코드·공식 출처·조회일·검증 한계를 명시하고 사용자 결정에 필요한 범위와 위험을 구분하면 조사 완료다. 문서 링크와 diff 검사를 수행한다. 제품 코드·디자인 확정 규칙·시안은 변경하지 않고 전체 플랫폼 CI·배포·실제 사용자 세션 실행도 하지 않는다.

첫 계획 커밋·push·Draft PR만 승인 범위다. 결과 문서는 미커밋으로 제출하고 최종 커밋·push·병합은 사용자 승인을 기다린다.
