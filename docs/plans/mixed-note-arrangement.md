# 웹·캡처 메모 정렬 누락 수정 계획

기준: 2026-11-15, origin/main 307f7fde87874763e6c5c5009fd903ae2a6949c0.

사용자 제보는 웹·캡처 메모가 측면·타일 정렬에서 빠진다는 것이다. 실행 재현과 코드 추론은 분리한다. 실제 기능은 오른쪽 제스처의 오른쪽 정렬, 위 제스처의 바둑판 정렬이며 왼쪽은 취소다.

- [x] 지침·최신 main·명령 매핑·최근 종료 이슈 확인
- [ ] 유형별 대상 수집·크기·생성 순서·숨김·수동 제외·진입 전환 조사
- [ ] 최소 수정과 두 정렬·이미지 비율·웹/터미널 크기·취소 회귀 검사
- [ ] 디자인 시스템·연결 시안과 검증 출처 갱신
- [ ] 관련 검사와 개발 빌드, 팀장 GUI 차례 이후 전용 인스턴스 실행 확인
- [ ] 결과 제출 후 제품 커밋·push·병합 승인 대기

범위 밖: 일반 열기 배치 정책 변경, 다른 작업의 미커밋 코드, 사용자 기존 창 변경, 외부 웹 탐색·실제 셸 실행, 전체 플랫폼 CI·릴리스.

현재 코드 확인: managed_windows는 웹 host를 합치지만 arrange는 memo_id_from_window로 웹·터미널을 제외한다. 캡처는 note-image label로 이 조건을 통과하므로 동일 원인이라고 단정하지 않는다. auto_layout_excluded는 명시적 arrange에서 검사하지 않는다.
