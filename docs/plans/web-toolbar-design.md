## 범위와 판단

공통 `style.css`·`toolbar.js`·Tabler 아이콘을 유지하고 웹 전용 CSS의 고정 색상·버튼 스타일 덮어쓰기를 제거한다. 공통 30px 행, 24×22px 버튼, 12px 아이콘, 접힌 24px 창과 오른쪽 두 슬롯을 적용한다. 텍스트 읽기 화면만의 22px 행 예외는 웹에 확대하지 않는다. 메모 appearance 설정을 신뢰된 chrome에 적용하며 외부 콘텐츠의 색상에는 개입하지 않는다.

핀은 이미 지원되는 web_chrome 동작과 aria-pressed를 유지한다. #119의 세션 종료는 이번 범위가 아니며 닫기는 숨김·페이지 유지다. 외부 콘텐츠 IPC 거부, 탐색/다운로드 정책, native 프레임·최소 크기를 보존한다. 앱과 기본 스킬의 작업 흐름은 변경하지 않는다.

## 구현 결과

외부 콘텐츠가 제목줄 높이만큼 툴바를 덮는 실제 macOS 문제를 확인해 `web.rs`의 child 위치/resize 경로도 보정했다. 고정 OS 수치 대신 native frame/contentLayoutRect를 사용한다. 상세 근거와 미검증 범위는 [검증 기록](../verification/web-toolbar-design-20261113.md)을 따른다. 최종 제품 변경은 미커밋이며 승인 대기한다.

사용자 후속 요청: 시안의 OS 제목줄 제거. decorations(false), 신뢰된 web_chrome 경계의 이동/resize, 외부 콘텐츠 가장자리3px 확보를 추가했다. 기본 main은 #150 병합으로 1f854b3이 되었으므로 제품 커밋 승인 후 rebase·관련 재검증이 필요하다. 현재 미커밋 변경을 보존하며 main은 건드리지 않는다.
