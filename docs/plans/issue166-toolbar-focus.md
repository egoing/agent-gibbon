# #166 툴바 Tab 포커스 톤다운

불투명 전경색 2px 테두리를 전경색 28% 알파로 낮춘다. 공통 메모·이미지·터미널·웹 chrome에 적용하며 버튼 크기와 포커스 이동은 유지한다. forced-colors에서는 시스템 Highlight를 사용한다.

- [x] CSS 구현 및 밝음·회색·검정 렌더 비교
- [x] 관련 UI 검사 (198개 및 브라우저 회귀 통과)
- [x] 개발 빌드: 초기 디스크 부족 실패 후 재시도·최신 main 통합 빌드 통과
- [x] 실제 개발 CLI 출처 확인 및 검증 메모 정리
- [ ] native Tab 화면: GUI 도구 식별 불가로 미검증 (팀장 확인 후 브라우저 근거로 제출)
- [x] 디자인 시스템·SVG·PNG 및 검증 근거 갱신
- [x] 최종 제품 커밋·push·병합 승인: 사용자 close 호출

물리 GUI는 팀장 예약 후에만 사용한다. main 갱신은 close 승인 및 팀장 슬롯 배정 후 수행하며 기존 package-lock 변경은 보존한다.
