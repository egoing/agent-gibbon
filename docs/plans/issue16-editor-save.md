# #16 편집 저장 단축키 계획

기준: 2026-11-13, origin/main `9904f10770d552b8f90ceb8073415d9875c09062`.

## 범위와 완료 기준

- 편집 중 Command S / Ctrl S는 기존 저장 버튼과 같은 save_note 경로로 메모와 연결 원본에 반영한다.
- 읽기·이미지 메모는 기존 파일 내보내기를 유지한다. 편집 초안 내보내기는 Action Bar의 명시적 파일 내보내기 버튼으로 제공하며 새 단축키는 만들지 않는다.
- 본문·Feedback 포커스에서 동작을 통일하고 저장/내보내기 완료 문구와 접근성 안내를 구분한다.
- 중복 입력·조합 입력·저장 실패·원본 충돌에서 초안과 보호 동작을 확인한다. 취소 후 읽기 상태와 이미지 내보내기를 회귀 확인한다.
- 디자인 시스템과 관련 시안을 갱신하고 UI 테스트·Rust 검사·개발 빌드 및 출처를 확인한 전용 CLI/GUI 검증을 수행한다. GUI는 팀리더 예약 후 사용한다.

#140의 체크박스·렌더러·CSS는 이번 범위가 아니다. 전체 플랫폼 CI·배포는 실행하지 않는다.
첫 계획 커밋·push·Draft PR만 승인 범위이며 최종 구현은 로컬 미커밋으로 보존해 승인을 기다린다.
