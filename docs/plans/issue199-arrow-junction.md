# #199 화살촉과 곡선 접합 조사

기준 커밋 22dc7de의 사용자 제보 이미지에서 도착 메모 아래의 삼각형 옆으로 곡선이 들어오는 모습을 확인했다. 양 끝 메모의 원래 좌표와 배율은 알려지지 않았다.

1. 제품의 Rust 포트·제어점·로컬 변환을 호출하고 현재 HTML/CSS/JS를 독립 브라우저에서 렌더한다. 원본의 삼각형 높이와 곡선 진행 방향을 비교한다.
2. 정상 간격·짧은 간격·접촉·겹침에서 포트 법선과 화살촉 밑변 사이를 지나는 선의 위치를 검사한다. 시작/끝, 방향 반전, 배율 변화와 창 경계 잘림을 구별한다.
3. 재현된 기하 결함에 한해 전후 픽셀과 회귀 검사를 확보하고 기존 포트·색·방향 설정과 별도 native 동작을 보존한다. 원인이나 원래 조건을 확인하지 못한 부분은 별도로 기록한다.

사용자 실제 창을 조작하지 않고 확인 가능한 범위를 검증한다. 물리 화면·포커스·네이티브 창 배치는 재현 범위에 포함하지 않는다.
