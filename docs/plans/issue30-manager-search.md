# 메모 목록 검색과 갱신 검증 계획 (#30)

- main 22dc7de의 관리 창을 합성 메모 1,000개로 실행해 초기 조회, 반복 조회, 타 메모 갱신 시 전송량·행 DOM 변경·선택 이미지 요청을 비교한다.
- 목록에 제목과 본문 텍스트 검색을 추가한다. 읽기 전용 목록에서 한글 조합과 키보드 포커스·스크롤을 유지하고 결과가 없으면 상태를 표시한다.
- 검색 결과에서 선택 항목이 사라지면 상세보기를 비우고, 항목이 다시 보이면 선택을 복원한다. 사용자가 다른 행을 명시 선택하면 그 선택을 유지한다.
- 변경된 본문만 전송하고 색인을 갱신하는 조건부 조회를 검증한다. 기존 조회 호환성, 선택 이미지 변경, 추가·삭제·지연·오류와 재시도를 포함한다.
- 디자인 시스템과 연결 시안을 갱신하고 로컬 Rust·UI 검사와 독립 브라우저 시험으로 확인한다. 운영 앱과 사용자 메모를 사용하지 않는다.
