# macOS 무인자 자동 재실행 명령 조사

2026-11-14에 macOS 15.6.1(24G90), Apple Silicon 환경에서 조사했다. 설치된 명령과 로컬 man 페이지, Apple 공개 문서를 확인했다. 허용 여부는 앱 종료 직전에 실행 중이던 프로그램을 새 프로세스로 열었을 때의 동작을 기준으로 판단했다.

## 결과

기본 제공 명령 중 무인자로 계속 정보를 갱신하는 도구는 `nettop`과 `top`이 적합하다. 현재 장비에서 `nettop`은 실제 실행 파일과 인자 수까지 확인할 수 있었다. `top`은 계속 실행되지만 인자 수 조회가 실패하므로, 현재 검증 방식에서는 편집 가능한 추천으로 남긴다. 설치 도구 `htop`·`btop`은 기본 제공 명령과 별도로 기존 지원을 유지한다.

명령 이름만으로 자동 재실행을 결정하지 않는다. 전경 프로세스의 실행 파일과 사용자 인자가 0개인 사실을 확인해야 한다. macOS의 `argc=1`은 실행 파일 이름 한 개만 있어 사용자 인자가 0개라는 뜻이다. 실행 파일을 찾지 못하거나 인자 수를 확인할 수 없으면 복원 추천으로 처리한다.

## 기본 제공 명령별 판단

| 명령 | 인자 없는 기본 동작 | 판단과 이유 |
|---|---|---|
| `nettop` | 소켓·라우트 정보를 계속 갱신 | 허용. 작업 대상 인자가 필요 없고 네트워크 모니터 화면을 다시 열 가치가 있다. |
| `top` | 프로세스 정보를 계속 갱신 | 후보. 무인자 실행의 용도는 적합하다. 현재 장비의 인자 수 조회 실패를 해결해야 자동 허용할 수 있다. |
| `iostat` | I/O·CPU 통계를 한 번 출력 | 제외. 계속 갱신하려면 주기나 횟수 인자가 필요하다. |
| `vm_stat` | 가상 메모리 통계를 한 번 출력 | 제외. 계속 갱신하려면 주기 인자가 필요하다. |
| `nfsstat` | NFS 클라이언트·서버 통계를 출력 | 제외. 계속 갱신하려면 주기 인자가 필요하다. |
| `netstat` | 네트워크 상태를 출력 | 제외. 지속 관찰 모드에는 별도 옵션이 필요하다. |
| `lsof` | 열린 파일 목록을 출력 | 제외. 반복 관찰에는 별도 옵션이 필요하다. |
| `df` | 파일시스템 사용량을 출력 | 제외. 단발 조회이므로 종료 전의 실행을 새로 이어갈 상태가 없다. |
| `du` | 현재 경로 아래 사용량을 계산해 출력 | 제외. 큰 디렉터리에서 디스크 탐색을 반복하게 된다. |
| `uptime` | 시스템 가동 시간과 부하를 출력 | 제외. 단발 조회다. |
| `w` | 로그인 사용자와 활동을 출력 | 제외. 단발 조회다. |
| `who` | 로그인 사용자 목록을 출력 | 제외. 단발 조회다. |
| `fs_usage` | 파일시스템 관련 커널 추적 | 제외. root 권한이 필요하다. |
| `sc_usage` | 지정 프로세스의 시스템 호출 통계 | 제외. 대상 프로세스와 root 권한이 필요하다. |
| `latency` | 스케줄링·인터럽트 지연을 커널 추적 | 제외. root 권한이 필요하다. |
| `iotop` | DTrace 기반 I/O 모니터링 | 제외. root 권한이 필요하다. |
| `powermetrics` | 전력·CPU 등의 샘플링 도구 | 제외. 일반 사용자 권한으로 자동 시작할 대상으로 확정하지 않았다. |
| `eslogger` | 지정 Endpoint Security 이벤트 기록 | 제외. 이벤트 이름·root·전체 디스크 접근 권한이 필요하다. |
| `vmmap` | 대상 프로세스의 가상 메모리 맵 조회 | 제외. 대상 프로세스 인자가 필요하다. |
| `sample` | 대상 프로세스를 샘플링 | 제외. 대상 프로세스 인자가 필요하다. |
| `leaks` | 대상 프로세스의 메모리 누수 검사 | 제외. 대상 프로세스 인자가 필요하다. |
| `ping` | 목적지 지정이 필요 | 제외. 무인자로 연결할 대상을 복원할 수 없다. |
| `traceroute` | 목적지 지정이 필요 | 제외. 무인자로 경로를 추적할 대상을 복원할 수 없다. |
| `nc` | 연결 방식·대상 등의 지정이 필요 | 제외. 무인자로 이전 연결을 복원할 수 없다. |
| `tcpdump` | 네트워크 패킷 캡처 도구 | 제외. 캡처 권한·장치와 수집 범위 확인이 필요하다. |
| `log` | show·stream 등 하위 명령 필요 | 제외. 단독 이름으로 이전 조회를 이어갈 수 없다. |
| `bc` | 대화형 계산기 | 보류. 다시 열 수 있으나 변수·함수·계산 내용이 이어지지 않는다. `BC_ENV_ARGS`로 초기 동작도 달라질 수 있다. |
| `dc` | 대화형 스택 계산기 | 보류. 스택·레지스터가 이어지지 않는다. `DC_ENV_ARGS`로 초기 동작도 달라질 수 있다. |
| `vi`·`vim` | 빈 편집기를 시작 | 보류. 무인자 재시작으로 편집 버퍼·미저장 내용을 복구하지 못한다. 시작 설정에 따른 동작도 있다. |
| `nano` | 이 장비에서는 pico 편집기를 시작 | 보류. 무인자 재시작은 빈 편집기를 연다. 편집 내용 복구는 별도 설계가 필요하다. |
| `less`·`more` | 입력을 읽거나 파일 지정을 기다림 | 제외. 이전 파일·파이프 입력·페이지 위치를 복구하지 못한다. |
| `cat`·`tail` | 표준입력을 읽음 | 제외. 기존 파이프 입력이 이어지지 않는다. |
| `screen` | 새 셸을 실행하는 새 화면 생성 | 보류. 기존 세션에 다시 연결하려면 세션 선택이 필요하다. 설정 파일에 따른 시작 동작도 있다. |
| `bash`·`zsh`·`sh` | 셸 시작 | 보류. 현재 작업 경로와 기본 셸을 여는 Welcome 흐름에서 처리할 범위다. 내부 작업 상태를 복구하지 못한다. |
| `script` | 셸과 대화 기록 파일 생성 | 제외. 자동 재실행으로 파일 기록을 시작하게 된다. |
| `caffeinate` | 잠자기를 방지하는 assertion 생성 | 제외. 자동 재실행이 시스템 전원 동작을 바꾼다. |
| `memory_pressure` | 메모리 압력을 측정·생성하는 도구 | 보류. 무인자 실행의 지속 관찰 동작을 실측하지 않아 이번 허용 목록에는 포함하지 않았다. |

표의 제외·보류는 이번 무인자 자동 재실행 목록에 관한 판단이다. 사용자가 편집한 실행 계획으로 직접 시작할 수 있는지와 이전 작업 내용을 복구할 수 있는지는 각각 따로 검증해야 한다.

## 현재 장비의 실행 검증

GUI 창을 띄우지 않고 독립 PTY에서 실행했다. 크기는 110열×30행, `TERM=xterm-256color`로 설정했다. 출력을 계속 읽어 버리고 2초 안에 자체 종료하는지 확인했다. 지속 프로세스는 검사 직후 이번 검사 PID만 종료했다. 원시 출력·명령 인자·환경 변수는 결과 파일에 저장하지 않았다.

| 실행 파일 | 무인자 실행 결과 | 인자 수 검증 |
|---|---|---|
| `/usr/bin/nettop` | 2초 후에도 갱신 중 | Darwin `KERN_PROCARGS2`의 `argc=1` 확인 |
| `/usr/bin/top` | 2초 후에도 갱신 중 | `KERN_PROCARGS2` 조회에서 `EINVAL` |
| `/usr/sbin/iostat` | 출력 후 종료 | 지속 프로세스가 없어 조회 생략 |
| `/usr/bin/vm_stat` | 출력 후 종료 | 지속 프로세스가 없어 조회 생략 |
| `/usr/bin/nfsstat` | 출력 후 종료 | 지속 프로세스가 없어 조회 생략 |

PTY 출력을 읽지 않으면 단발 프로그램도 출력 버퍼에서 멈춰 계속 실행 중인 것처럼 보일 수 있다. 이번 검증에서는 PTY를 계속 읽어 그 오판을 피했다. 위의 PTY 검사는 앱 재시작·WebView·서브 모니터 동작 검증을 대체하지 않는다.

## 추가 설치 도구

`htop`·`btop`은 기존 실기기 검증을 유지한다. `btm`(bottom), `nmon`, `gotop` 같은 자원 모니터도 확장 후보가 될 수 있다. 기본 macOS 제공 도구가 아니며, 이번 작업에서 설치·실행·시작 설정을 검증하지 않아 허용 목록에는 추가하지 않았다.

## 근거

상세 기본 동작과 권한 조건은 이 장비의 `man nettop`, `man top`, `man iostat`, `man vm_stat`, `man nfsstat`, `man fs_usage`, `man sc_usage`, `man latency`, `man iotop`, `man powermetrics`, `man eslogger`, `man bc`, `man dc`, `man vim`, `man screen`, `man script`, `man caffeinate`를 확인했다.

Apple 공개 문서는 `top`의 주기적 프로세스 표시와 `vm_stat`의 기본 단발 출력을 설명한다. [Apple top 매뉴얼](https://github.com/apple-oss-distributions/top/blob/main/top.1), [Apple 가상 메모리 사용량 문서](https://developer.apple.com/library/archive/documentation/Performance/Conceptual/ManagingMemory/Articles/VMPages.html)

`iostat`과 `vm_stat`의 기본·반복 출력 분기는 Apple 공개 소스에서도 확인할 수 있다. [Apple iostat 소스](https://github.com/apple-oss-distributions/system_cmds/blob/main/iostat/iostat.c), [Apple vm_stat 소스](https://github.com/apple-oss-distributions/system_cmds/blob/main/vm_stat/vm_stat.c)
