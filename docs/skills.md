# 스킬 관리

설정의 **스킬**에서 메모 관리와 작업 진행 표시를 펼치고 On/Off를 바꾼다. 초기에는 모두 Off이며 별도 저장 버튼 없이 반영한다. 스킬을 켜는 것은 지침을 설치하는 행동으로, 에이전트를 실행하거나 작업을 시작하지 않는다. 화면 기준은 [디자인 시스템](design-system.md#스킬-관리--67-2026-11-06)을 따른다.

## 제공 항목

| 화면 이름 | 스킬 ID | 내용 |
|---|---|---|
| 메모 관리 | agent-gibbon | 기존의 워크플로우 중립적인 메모 생성·조회·갱신·숨기기 지침 |
| 작업 진행 표시 | agent-gibbon-progress | 선택한 작업의 계획·완료·미검증 범위를 한 플로팅 체크리스트에 유지하는 지침 |

화면 설명 그리기·클라우드 모니터링처럼 기반 기능이 없는 예시 스킬은 포함하지 않는다. 기본 사용 스킬 자체에 모든 작업의 진행 메모를 강제하지 않는다.

## 지원과 설치 위치

현재 자동 설치 대상은 로컬 **Codex CLI와 Claude Code**다. PATH와 알려진 사용자 설치 폴더의 실행 파일을 찾으며, 로그인 셸·후보 에이전트를 실행하지 않는다. 로그인·권한·현재 실행 중인 세션의 새 스킬 재탐색까지 보장하는 것은 아니다. 각 에이전트가 새 지침을 읽는 시점에는 해당 제품의 정책이 적용된다.

| 대상 | 사용자 설치 위치 |
|---|---|
| Codex | `~/.agents/skills/<스킬 ID>/` |
| Claude Code | `~/.claude/skills/<스킬 ID>/` 또는 절대 경로 `CLAUDE_CONFIG_DIR/skills/<스킬 ID>/` |

Codex는 [공식 사용자 스킬 위치](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills), Claude Code는 [공식 개인 스킬 위치](https://code.claude.com/docs/en/skills#choose-where-skills-load)를 사용한다. `CLAUDE_CONFIG_DIR`는 홈의 조상이나 파일시스템 루트를 대상으로 삼지 않는다. 스킬 루트의 의도적인 공유 링크는 실제 경로로 정규화하고 중복 대상을 제거한다. 개별 스킬의 링크는 링크 항목 자체를 교체하며 외부 원본을 따라가 덮어쓰지 않는다.

프로젝트별 설치, 에이전트 선택, WSL·원격 호스트, 다른 에이전트의 등록 방식은 이번 범위에 포함하지 않는다. 앱과 두 지침은 macOS·Windows 실행 경로를 설명하지만, 플랫폼별 실제 검증 범위는 [검증 기록](verification/issue67-skills.md)을 따른다.

## On/Off와 업데이트

On으로 켤 때 기존 설치본과 로컬 수정 내용은 배포본으로 교체한다. 설치와 설정 저장이 끝나기 전에는 성공한 On으로 표시하지 않는다. Off는 설치 기록과 소유 표식이 있는 앱 관리 사본만 제거한다. 앱에서 관리한 적 없는 수동 설치본과 다른 이름의 스킬은 건드리지 않는다. 사용자가 소유 표식을 지우거나 관리 사본을 외부 링크로 바꿨다면 해제를 거절하고 오류를 표시한다.

설정은 OS 앱 데이터 폴더의 `skills/settings.json`에 저장한다. 에이전트의 사용자 전역 스킬을 관리하므로 같은 사용자 앱 인스턴스가 이 상태와 파일 잠금을 공유한다. 비밀정보나 계정 토큰은 저장하지 않는다.

앱 버전과 포함한 지침의 SHA-256을 설치 revision으로 기록한다. 앱 실행 또는 스킬 설정 진입 시 revision이 바뀐 On 항목을 재설치하며, 일반 실행마다 모든 설치본을 무조건 덮어쓰지 않는다. 새로 감지한 에이전트와 누락된 On 사본은 설치한다. Off 선택은 업데이트로 활성화하지 않는다. 실패한 업데이트는 이전 revision을 유지해 다음 실행·스킬 설정 진입 때 재시도한다. 약관 확인 전에는 스킬 명령·자동 설치를 막으며 최초 약관 확인 뒤에도 동기화한다.

설치 교체·Off 제거와 설정 저장을 하나의 로컬 트랜잭션으로 처리한다. 도중 실패하면 이전 사본을 복원한다. 앱이 중단됐다면 다음 스킬 작업 전에 `transaction.json`과 저장 상태를 비교해 복구하거나 완료된 작업의 백업만 정리한다. 임시 사본·백업은 에이전트의 스킬 검색 폴더 밖에 두어 중복 스킬로 로드되지 않게 한다.

## 포함 배포와 오프라인 조건

지침은 Rust 바이너리에 `include_str!`로 포함한다. 설치·업데이트에 Node.js, npx, Git 다운로드, 서버, 네트워크 연결을 요구하지 않는다. 앱 업데이트 파일을 내려받는 과정과 에이전트 자체의 설치·인증은 별도다.

Orca 설치본의 내부 감지·직접 배치 코드와 `npx skills --help`를 조사했다. skills CLI의 agent/global/copy 옵션은 확인했으나 이 앱의 런타임에는 사용하지 않는다. 앱은 소수의 포함된 지침만 관리하므로 Rust에서 직접 설치해 오프라인 배포와 명시적인 덮어쓰기·Off·오류 복구 경계를 유지한다. CLI 후보의 도움말은 조사 근거이며, 해당 도구로 실제 설치·업데이트를 검증했다는 뜻은 아니다. [skills 공식 안내](https://github.com/vercel-labs/skills)를 참고할 수 있다.
