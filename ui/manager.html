자동 업데이트

공식 설치본은 새 버전을 자동으로 내려받습니다. 5분 동안 입력이 없고 진행 중인 작업이 없으면 설치하고 다시 시작합니다.

업데이트 상태를 확인하는 중입니다.

설치가 보류되거나 실패했나요?

‘업데이트하고 재시작’은 5분 대기만 생략합니다. 편집·저장·내보내기와 캡처를 마치고, 실행 중인 터미널을 종료한 뒤 숨긴 터미널도 관리 창에서 삭제하세요. 작업이 안전한지 확인한 후 설치합니다.

안내 닫기는 자동 설치를 끄지 않습니다. 보류 조건이 해소되면 자동으로 다시 확인합니다. 응답 대기 시간이 초과되면 작업을 저장하고 다시 시도하세요.

다운로드·검증 오류는 연결 상태를 확인한 뒤 ‘다시 확인’으로 다시 받으세요. 반복되면 공식 릴리스의 운영체제와 CPU에 맞는 설치 파일로 수동 설치하세요. 검증 실패를 무시하고 설치하지 않습니다.
