# 곁에 두고 보기

캡처, 메모, 터미널, 브라우저를 다른 창 위에 띄워 두고, 작업 중에 편하게 참조하세요.

메뉴 막대나 트레이에서 필요한 기능을 고른 뒤, 화면에 원하는 영역을 그려 보세요.

- **영역 캡처** · 화면 일부를 찍어 곁에 두세요.
- **영역 텍스트 메모** · 기억할 내용이나 할 일을 적어 두세요.
- **영역 터미널** · 명령을 실행하고 결과를 확인하세요.
- **영역 웹 창** · 웹 주소를 열어 자료를 함께 보세요.

**이 메모로 시작해 보세요**

본문을 드래그해 옮기고, 가장자리를 끌어 크기를 조절하세요. 연필 버튼으로 내용을 고쳐 쓸 수 있어요.

숨긴 창은 메뉴 막대나 트레이에서 다시 열 수 있어요. 각 기능의 단축키도 메뉴에서 확인하세요.
