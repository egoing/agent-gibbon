# Keep it nearby

Keep captures, notes, terminals and web pages above your other windows for easy reference.

Choose an action from the menu bar or system tray, then drag to select a region on the screen.

- **Capture a region** · Keep a snapshot of part of the screen.
- **Text note in a region** · Write down a reminder or a task.
- **Terminal in a region** · Run commands and check the output.
- **Web window in a region** · Open a web page alongside your work.

**Try it with this note**

Drag the body to move the note, or drag an edge to resize it. Use the pencil to edit the text.

Reopen hidden windows from the menu bar or tray. The menu also lists the shortcuts for each action.
