# 手元に置いて見る

キャプチャ、メモ、ターミナル、ウェブページをほかのウィンドウの手前に置いて、作業しながら参照できます。

メニューバーまたはシステムトレイで機能を選び、画面をドラッグして範囲を指定してください。

- **範囲をキャプチャ** · 画面の一部を撮って手元に置けます。
- **範囲にテキストメモ** · 覚えておきたいことや予定を書き留めます。
- **範囲にターミナル** · コマンドを実行して結果を確認します。
- **範囲にウェブウィンドウ** · ウェブページを開いて作業中の資料と並べます。

**このメモで試してみましょう**

本文をドラッグすると移動でき、端をドラッグするとサイズを変更できます。鉛筆ボタンで内容を編集できます。

隠したウィンドウはメニューバーやトレイから再表示できます。各機能のショートカットもメニューで確認できます。
